# Multiplayer Environment Editor
Adds a bunch of fun options for customizing the environment in multiplayer Beat Saber matches.

## DESIGNED FOR BEAT SABER 1.40.8 - OTHER VERSIONS ARE UNTESTED

# Toggleable Features
- Singleplayer Enviornment override
- Hide Player Notes and Walls (automatically enabled during Noodle Extensions, Mapping Extensions, and Vivify maps)
- Hide Players Entirely
- Change spacing between player platforms
- Disable player movement restrictions
- Disable 1st place hologram (Also automatically enabled during Noodle Extensions, Mapping Extensions, and Vivify maps)

# Install
- Simply head to [releases](https://github.com/Minibattle/MultiplayerEnviornmentEditor/releases) and download the zip.
- Drag the "MultiplayerEnvironmentEditor.dll" into your Beat Saber plugins folder
- Enjoy!
